# Косынка — Telegram Mini App

Полноценный локальный пасьянс Klondike на React + TypeScript + Vite. Интерфейс на русском языке, без сервера, регистрации, платных изображений и токенов в клиентском коде.

## Локальный запуск

Нужен Node.js 22.12+ (или 24 LTS) и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, выведенный Vite (обычно http://localhost:5173). В обычном браузере Telegram необязателен. Официальный SDK подключён из `https://telegram.org/js/telegram-web-app.js`; при его недоступности сама игра продолжает работать после завершения попытки загрузки скрипта.

## Проверки и сборка

```sh
npm test
npm run build
npm run preview
```

Браузерная проверка (во втором терминале, при работающем `npm run dev -- --port 5173`):

```sh
npx playwright install chromium
npm run test:browser
```

Она использует отдельный браузерный профиль, не затрагивая пользовательское сохранение. Проверяет касания, перетаскивание мышью и сенсорные Pointer Events, отмену, перезагрузку, режим по три, подсказки, правила, ширину 320–1280, короткое окно и победный автосбор. Снимок сохраняется в игнорируемый Git каталог `test-results/`.

Готовые статические файлы находятся в `dist/`. `npm run preview` предназначен для локальной проверки сборки, а не для постоянного хостинга.

## Размещение на HTTPS

Можно использовать любой статический HTTPS-хостинг. Загрузите **содержимое** `dist/` в корень сайта либо подключите этот репозиторий к выбранному хостингу с настройками:

- install: `npm ci`
- build: `npm run build`
- output / publish directory: `dist`
- Node.js: 22.12+ или 24 LTS

Сайт должен открываться по публичному HTTPS-адресу без входа в аккаунт хостинга. Относительный `base` позволяет размещать игру и в подкаталоге. Не запрещайте встраивание через `X-Frame-Options: DENY` или `frame-ancestors 'none'`: Telegram Web может использовать iframe. Не добавляйте HTTP Basic Auth. Не храните секреты в переменных `VITE_*`: они попадают в браузерную сборку.

## Подключение к боту — самостоятельно

1. Откройте официального [@BotFather](https://t.me/BotFather). Создайте бота командой `/newbot`, если его ещё нет. Полученный токен храните отдельно; этой игре он не нужен.
2. Отправьте `/setmenubutton`, выберите бота, укажите публичный HTTPS-адрес игры и текст кнопки «Играть в Косынку». Также настройка доступна через `/mybots` → бот → Bot Settings → Menu Button.
3. Откройте личный чат с ботом и нажмите настроенную кнопку меню. Игра должна открыться внутри Telegram.
4. По желанию включите Main Mini App в Bot Settings → Configure Mini App и задайте тот же адрес: появится запуск из профиля бота. Названия пунктов могут зависеть от версии интерфейса BotFather.
5. Проверьте на реальных iOS/Android: safe area, перетаскивание, вибрацию, сворачивание, возврат и сохранение. Проверка в обычном браузере не заменяет проверку Telegram-клиента.

Кнопка меню не требует постоянно работающего бота-сервера. Если нужна именно кнопка под ответом `/start`, потребуется отдельный обработчик бота: отправляйте `reply_markup.inline_keyboard` с `{"text":"Играть в Косынку","web_app":{"url":"ВАШ_HTTPS_URL"}}`. Токен должен быть только в серверном окружении этого обработчика. Сам Mini App не отправляет сообщения и не использует персональные данные Telegram.

Официальная документация: https://core.telegram.org/bots/webapps (SDK, кнопки запуска, темы, события высоты и safe area).

## Правила и управление

- Столбцы: убывание и чередование цветов; можно переносить открытые цепочки. В пустое место — короля.
- Основания: каждая масть отдельно, от туза до короля. Верхнюю карту основания можно вернуть в столбец.
- Колода: по одной или по три карты, неограниченное число проходов. Доступна только верхняя карта сброса.
- Перетаскивание мышью/пальцем; альтернатива — карта, затем место назначения. Двойное нажатие переносит карту в основание, если это разрешено.
- Новый режим применяется при новой раздаче, после подтверждения сброса партии.
- Отмена включает раздачу, повтор колоды и автоматический переворот. Каждый перенос автосбора можно отменить.
- Автосбор доступен только без колоды/сброса, со всеми открытыми картами и после конечной симуляции успешного завершения.
- Таймер считает активное время: скрытое приложение и открытое окно правил/новой партии приостанавливают его. Отмена восстанавливает счётчик ходов, но не откатывает время.
- Случайные раздачи не гарантированно решаемы. Подсказки не являются решателем.

## Архитектура и сохранение

- `src/game.ts`: чистые правила, генерация колоды, переносы, отмена, подсказки, проверка целостности, сериализация, автосбор.
- `src/App.tsx`: интерфейс, Pointer Events, двойные нажатия, доступные назначения, таймер, localStorage.
- `src/telegram.ts`: официальный `window.Telegram.WebApp`, `ready()`, `expand()`, подписки на тему/высоту/safe area и поддерживаемая тактильная обратная связь.
- `tests/game.test.ts`: основные правила, ошибки, история, восстановление, симуляция множества ходов.

Состояние версии 1 и полная история хранятся в localStorage под ключом `kosynka.game.v1`. При восстановлении проверяются все карты и каждое сохранённое состояние. Повреждённое или несовместимое сохранение заменяется новой партией. Если запись невозможна (например, хранилище заполнено), показывается предупреждение; игра остаётся доступной в памяти. Сохранения привязаны к устройству, браузерному профилю и домену. Они не синхронизируются между устройствами; очистка данных браузера/Telegram удалит партию. Одновременно играйте в одной вкладке: последняя запись заменяет предыдущую.

## Что остаётся владельцу

Выбрать хостинг, опубликовать `dist/` по публичному HTTPS-адресу, настроить бота через BotFather и проверить игру внутри Telegram на своих устройствах. Локальный запуск или приватный предпросмотр сами по себе не означают подключения к боту.

В браузерах с экспериментальным `document.modelContext` доступен инструмент `show_solitaire_hint`, подсвечивающий тот же ход, что кнопка «Подсказка». Его отсутствие не влияет на игру. В этой среде настоящий WebMCP-контекст для проверки регистрации недоступен; эта дополнительная интеграция не считается проверенной.
