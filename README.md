# Косынка

Законченная standalone-версия классического пасьянса Klondike. Игра работает в обычном браузере на компьютере, планшете и телефоне, не требует аккаунта или сервера и хранит партию на устройстве.

## Возможности

- строгие правила Klondike: семь столбцов, четыре основания, перенос последовательностей и автоматическое открытие карт;
- режимы раздачи по одной и по три карты с неограниченным повторным проходом колоды;
- перетаскивание мышью, пальцем и стилусом, управление последовательными нажатиями и двойное нажатие для переноса в основание;
- полная отмена переноса, раздачи, повторного прохода и автоматического открытия карты;
- полезные подсказки без автоматического выполнения хода;
- безопасный финальный автосбор только после успешной симуляции оставшейся партии;
- детерминированная раздача по seed и повтор той же партии;
- таймер активного времени и единый счётчик ходов;
- локальная статистика отдельно для Draw 1 и Draw 3;
- настройки звука, анимаций, двойного нажатия и финального автосбора;
- адаптивный стол от 320 px, включая короткие экраны и мобильный landscape;
- собственные масштабируемые лица карт, раскладки символов 2–10, фигурные карты на SVG и декоративная рубашка без внешних изображений;
- анимации раздачи, переноса, переворота, stock/waste и победы;
- тихие синтезированные звуки через Web Audio API без сторонних аудиофайлов.

## Стек

- React 19 и TypeScript;
- Vite;
- Vitest для игровой логики и хранилища;
- Playwright для браузерных сценариев;
- CSS и Web Animations API для интерфейса и анимаций;
- Lucide React для служебных иконок.

## Установка и запуск

Нужен Node.js 22.12+ или 24 LTS и npm.

```sh
npm ci
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

## Сборка и проверки

```sh
npm run format
npm test
npm run build
npm run preview
```

Для браузерной проверки сначала установите Chromium, затем запустите dev-сервер на порту 5173 и smoke-suite во втором терминале:

```sh
npx playwright install chromium
npm run dev -- --port 5173
npm run test:browser
```

Готовая статическая сборка создаётся в `dist/`. Команда `npm run preview` нужна только для её локальной проверки.

## Управление

- Перетащите карту или открытую последовательность в подсвеченное место.
- Можно нажать на карту, а затем на подходящий столбец или основание.
- Двойное нажатие по доступной карте отправляет её в основание, если настройка включена.
- Нажатие на колоду открывает одну или три карты. Пустая колода с непустым сбросом начинает новый проход.
- «Отменить» возвращает последнее игровое действие целиком.
- «Подсказка» подсвечивает источник и назначение полезного хода.
- «Новая игра» создаёт новую раздачу или позволяет повторить текущую.

Время учитывается только при активной вкладке и закрытых модальных окнах. Один перенос, одно взятие из колоды или один повторный проход считаются одним ходом. Визуальные действия и подсказки ходами не считаются.

## Сохранение и статистика

Текущее состояние, история отмен, seed, время, настройки и статистика сохраняются в `localStorage`. После перезагрузки восстанавливается фактическое расположение всех карт. Каждое сохранение проходит проверку: в партии и каждом снимке истории должны находиться ровно 52 уникальные карты. Повреждённые или несовместимые данные игнорируются, после чего создаётся новая партия.

Статистика разделена по режимам Draw 1 и Draw 3. Партия считается незавершённой, когда игрок сделал хотя бы один ход и после этого начал новую или повторил текущую раздачу. Хранятся число партий и побед, процент побед, текущая и лучшая серии, лучшее время, минимум ходов и общее активное время. Данные остаются в текущем браузерном профиле и удаляются вместе с данными сайта.

## Структура проекта

- `src/game.ts` — чистая игровая модель, правила, seeded shuffle, история, подсказки, проверка целостности и автосбор;
- `src/App.tsx` — игровой стол, Pointer Events, таймер и координация интерфейса;
- `src/components/Card.tsx` — лица, символы, фигурные карты и рубашка;
- `src/components/Dialogs.tsx` — новая партия, правила, настройки, статистика и победа;
- `src/storage.ts` — проверяемое локальное сохранение и статистика;
- `src/audio.ts` — короткие синтезированные звуковые сигналы;
- `src/telegram.ts` — существующий необязательный адаптер Telegram Mini Apps;
- `tests/` — unit-тесты правил и persistence;
- `scripts/smoke.mjs` — desktop, mobile, responsive и victory E2E-сценарии.

## Поддерживаемые устройства

Основная цель — актуальные версии Chrome, Edge, Safari и Firefox с Pointer Events, CSS custom properties и `localStorage`. Интерфейс проверяется на ширинах 320, 360, 375, 390, 430, 768, 1024, 1280 и 1680 px, а также в мобильном landscape. При `prefers-reduced-motion` движения отключаются. Звук запускается только после пользовательского действия, как требуют современные браузеры.

## Future / Telegram integration

Существующий адаптер Telegram сохранён как задел: при наличии официального `window.Telegram.WebApp` он вызывает `ready()` и `expand()`, учитывает тему, высоту и safe area и использует доступную тактильную отдачу. В обычном браузере Telegram API не требуется и не влияет на игру.

Публикация, BotFather, серверная часть, платежи и монетизация не входят в текущий этап.
